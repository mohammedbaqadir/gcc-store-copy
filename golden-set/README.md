# Golden Set

Approved copies used for calibration and comparison. They show qualities — naturalness, structure, restraint, information density — never facts to reuse and never wording to copy mechanically.

Copies are preserved verbatim. Editing or removing one is a human decision.

| Example | Type | What it teaches |
|---|---|---|
| `examples/digital-card-stc-quicknet-unlimited-1-week/` | `digital_card` | Benefit-led hook; icon-led scan; limitation kept customer-facing |
| `examples/food-tamara-sukkary-rutab-500g/` | `food` | Cultural hook tied to the product; short, warm structure |
| `examples/ready-samsung-t7-shield-1tb-black/` | `ready_product` | Specs as purchase reasons; scannable confidence; truthful performance note |
| `examples/booking-shawir-legal-consultation-15-min/` | `booking` | Paragraph-led; no promised outcomes; plain commercial terms |
| `examples/made-to-order-custom-ceramic-mug-tabuwaprints/` | `made_to_order` | Scope-first; requirements as a customer checklist; honest option-dependent price |
| `examples/digital-product-jarir-prince-enchanted-ebook/` | `digital_product` | Content before metadata; honest digital delivery; clear return limitation |

Structures vary deliberately: the project has no mandatory description formula.
